SECTION 03Install

Four steps. One key.

Drop in, list in server.cfg, reboot, press F4. That's it.

01
Download
Grab the latest release from GitHub. Place the wraith folder in resources/.
02
Register
Add ensure wraith to your server.cfg. No dependencies.
03
Boot
Restart your RedM server. Configs hot-load on first menu open.
04
Open
Press F4 in-game. The wraith arrives.
~/redm-server — wraith
SECTION 04FAQ

Common questions.

Does this work with all RedM frameworks?+
Yes. Wraith ships framework-agnostic and includes targeted economy hooks for Bandera, Yellowstone, DRB, Dakota SV, GoldRush, Frontier and Silent River. New frameworks can be added in configs/economy.lua.
Is the menu keybind configurable?+
Yes — set any RegisterCommand-compatible key in configs/keys.lua. F4 is the default.
How does Wraith handle 6,000+ config entries?+
The Config Browser lazy-loads pages, debounces search, and keeps NPC/animal/vehicle lists in compact arrays. Open speed is identical whether you have 100 or 100,000 entries.
Can I extend the menu with my own modules?+
Yes. Drop a Lua file into modules/ exporting a tree node. Wraith merges it into the main menu at boot. The "Missing Labels" tools help you ship clean.
Where do I report bugs?+
GitHub Issues on the repo, or our Discord #bug-reports channel. Both linked in the footer.
